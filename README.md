### Featured Projects

**[Document Q&A Agent (RAG)](https://github.com/f20230125-sudo/document-qa-agent)**
Retrieval-augmented generation service — chunks and embeds documents with the Gemini API, indexes them in FAISS, and serves a Flask REST API that returns grounded, source-cited answers.

**[Support Ticket Triage Agent](https://github.com/f20230125-sudo/ticket-triage-agent)**
LLM agent that classifies customer support tickets and drafts replies as schema-validated structured JSON, using Gemini's structured output mode + Pydantic.

**[PR Diff Summarizer](https://github.com/f20230125-sudo/pr-diff-summarizer)**
Developer-tooling agent that turns a raw `git diff` into a structured PR summary — risk level, key changes, and testing notes — instead of a human writing it by hand.
